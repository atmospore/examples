# Atmospore examples

Small, runnable examples for the [Atmospore pollen forecast API](https://atmospore.com/api-docs). Each folder is self-contained: copy it, add your API key, run it.

| Example | What it shows | Guide |
|---|---|---|
| [`map-tiles`](map-tiles) | A live, global pollen map with MapLibre GL JS, fed by `GET /v1/map-tiles`. Node.js or Python backend, one HTML page. | [Add a live pollen map to your website or app](https://atmospore.com/article/map-tiles) |

Get an API key at [atmospore.com/account](https://atmospore.com/account). Some examples need a paid plan; each README says so.

Related: [atmospore-python](https://github.com/atmospore/atmospore-python) (Python client) · [atmospore-mcp](https://github.com/atmospore/atmospore-mcp) (MCP server for AI assistants).
